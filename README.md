# Bloom & Blush — Flower Shop Landing Page

A responsive, one-page aesthetic flower shop website made with **plain HTML, CSS, and JavaScript**. No build tools, frameworks, or package installs required.

## Preview locally
1. Download or extract this project.
2. Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, and this README.
3. In the repository, go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.

## Customize before publishing
- Replace the sample address in `index.html`.
- Update the opening hours and flower names/prices to match your shop.
- Replace the Instagram URL and email address with your real contact links.
- The sample email uses `hello@bloomandblush.example` and is not a real mailbox.
- Photos are loaded from Unsplash, and fonts from Google Fonts, so an internet connection is needed for those external assets.

## Files
- `index.html` — page content and sections
- `styles.css` — colors, layout, responsive styles
- `script.js` — mobile navigation and dynamic footer year
